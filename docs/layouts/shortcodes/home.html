What is Valet?

A validation gate for data files before they reach your warehouse.

Check CSV, Parquet, JSON or NDJSON files against your rules; the exit code decides whether ingestion proceeds.

Use cases

Where Valet fits.

01

Loading files into staging

Load only on exit 0. Rejects keep the original records.

02

Large uploads in a web service

Managed memory stays within a set budget, whatever the upload size.

03

Pipeline and CI gates

Airflow or CI blocks the next step on failed error-level checks.

Features

What you get.

01

More than format checks

Required values, ranges, keys, references, column relationships, dataset totals.

02

Rules as config

Versioned, reusable YAML or JSON; no per-input scripts.

03

Clear result

Aggregate JSON on stdout plus exit code; no files unless requested.

04

Row-level detail on request

Issues and Parquet/CSV outputs with provenance to source rows.

05

No extra service

Self-contained CLI; streaming shares one managed-memory budget.

06

Parquet schema only

Metadata-only command for names and types; values not checked.
