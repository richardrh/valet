Core capabilities

A strict, explicit validation pipeline.

Choose a metadata-only schema report or full validation with row checks, conversion, provenance and committed outputs. The result tells you what was—and was not—checked.

01

Schema-only Parquet checks

Check required columns and expected types from footer metadata. Value-dependent checks are explicitly marked not evaluated.

02

Rules people can read

Check nulls, strict ranges, column relationships, schemas, uniqueness, references and dataset totals.

03

Bounded by design

Decoder, batch, index and publication state is charged against a managed-memory budget.

04

Structured evidence

Choose artifact output for stable issue codes, row provenance and recoverable raw rejects with conversion diagnostics.

05

Stdout-first results

Full validation returns an aggregate JSON summary by default. Select an output destination for manifest-last artifacts.

06

Local or object storage

Read and publish locally or through S3-compatible storage with bounded multipart handling.
